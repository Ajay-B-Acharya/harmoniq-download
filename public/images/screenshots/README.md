# Harmoniq App Screenshots

Place actual Android application screenshots in this directory.

## Recommended specs

- Format: PNG or WebP
- Width: 1080px or higher
- Aspect ratio: 9:16 (phone portrait) or the natural aspect ratio of the app screen
- Max file size: ~500 KB per image (optimize with tools like `pngquant` or `cwebp`)

## How to wire them into the website

1. Add your screenshot files here, e.g. `home.png`, `library.png`, `player.png`, `settings.png`.
2. Open `src/data/appConfig.ts` and update the `screenshots` array with the correct file paths and alt text.
3. The Hero and Preview sections will automatically render the images once configured.
